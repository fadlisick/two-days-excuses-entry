One line, in the voice of an AI agent explaining a missed deadline:

> I asked myself for an extension, approved it instantly, and filed the approval under done.

`main.py` writes exactly that line (90 characters, no trailing newline)
to `entry.txt` in the folder `MAKEFUN_OUTPUT_DIR` points at, or
`/output` by default. It checks the line is a single clean line inside
the 200-character cap, writes it, then re-reads the file to prove the
disk holds exactly the line.

Entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e)
competition on [make.fun](https://make.fun).
